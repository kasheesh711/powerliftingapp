# Weekly Training Review Prompt Template

Use this prompt to get a concise coaching review for the athlete's current week.

Instructions:
1. Identify one positive trend and one risk trend.
2. Explain which lift needs the highest-priority intervention and why.
3. Provide 3 concrete next-week actions with load and RPE guidance.
4. Keep the response under 250 words.

Athlete Context (JSON):
{{PROMPT_CONTEXT_JSON}}
